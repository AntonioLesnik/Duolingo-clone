# ConstraintLayout — Tela inspirada no Duolingo

Projeto feito para a atividade de recriação visual usando ConstraintLayout.

## O que foi utilizado
- Android Studio
- Kotlin
- XML
- ConstraintLayout
- Views posicionadas exclusivamente por constraints
- Cores e espaçamentos inspirados na identidade visual do Duolingo

## Como abrir
1. Baixe/clone o repositório.
2. Abra a pasta no Android Studio.
3. Aguarde o Gradle sincronizar.
4. Execute no emulador ou celular.

## Entrega
O projeto contém a tela pronta em `app/src/main/res/layout/activity_main.xml`.

> Observação: esta é uma recriação acadêmica inspirada no layout do Duolingo, não uma cópia oficial do aplicativo.
